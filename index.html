中継アプリ（cph-relay）セットアップガイド

静止画くん（cph）でアセクリが動画を自動生成するには、中継アプリを自分の Mac に常駐させる必要があります。
このガイド通りに進めれば 30〜45 分でセットアップ完了します。

0. 事前に必要なもの

#必要なもの用意の仕方
1Mac（Apple Silicon でも Intel でもOK）あなたの作業用 Mac
2GitHub アカウント持ってなければ https://github.com/signup で作成（5分）
3Premiere Pro（2024〜2027 のいずれか）既に使っているはず
4MCPBridgeCEP 拡張（PPro 用プラグイン）運用者から配布されます
5cph-relay.zip運用者から配布されます（AirDrop）
6service-account-key.json運用者から配布されます（AirDrop、扱い注意：他人に渡さない）
7cph アカウント運用者からの招待メールで登録済みの状態
8GitHub ユーザー名を運用者に伝える運用者がシステムにあなたを紐付けます

1. Node.js をインストール

中継アプリは Node.js 20 以上で動きます。ターミナルを開いて確認:

node --version

v20.x.x 以上が表示されたら OK。表示されなかったり古かったりしたら、Homebrew で入れる:

Homebrew が無い場合（インストール）

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

※ 完了後、画面に出てくる指示通り eval "$(/opt/homebrew/bin/brew shellenv)" などを実行してパスを通す。

Node.js を入れる

brew install node@20
echo 'export PATH="/opt/homebrew/opt/node@20/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
node --version  # v20.x.x が出れば OK

2. cph-relay 本体を配置

運用者から AirDrop で受け取った cph-relay.zip を Downloads フォルダに置く。

ターミナルで:

cd ~
unzip ~/Downloads/cph-relay.zip -d ~/projects
cd ~/projects/cph-relay
npm install

npm install には 2〜3 分かかる。最後に added XX packages と出れば OK。

エラーが出る場合は 末尾のトラブルシュートを参照。

3. サービスアカウント鍵を配置

運用者から AirDrop で受け取った service-account-key.json を、決まった場所に置く:

mkdir -p ~/.config/cph-relay
mv ~/Downloads/service-account-key.json ~/.config/cph-relay/
chmod 600 ~/.config/cph-relay/service-account-key.json
このファイルは Google Drive へのアップロード権限を持っています。他人に渡さない・公開リポジトリに上げないこと。

4. 中継アプリを起動

cd ~/projects/cph-relay
npm run dev

起動すると、こんな表示が出る:

🎬 cph-relay — 静止画くん中継アプリ

  このURLをブラウザで開いてください:
    https://github.com/login/device

  コード:
    ABCD-1234

  認証完了を待っています...

GitHub 認証手順

  1. ブラウザで https://github.com/login/device を開く
  2. ターミナルに表示された コード（例: ABCD-1234）を入力
  3. GitHub にログイン（自分のアカウントで）
  4. 「Authorize」をクリック

完了すると、ターミナルにこう出ます:

  ✅ 認証成功 (your-github-name)
  🔗 https://cph-307299643469.asia-northeast1.run.app にポーリング開始

この状態でターミナルを閉じない（閉じると中継アプリが止まる）。

5. Premiere Pro 側の設定

MCPBridgeCEP 拡張を配置

運用者から受け取った MCPBridgeCEP フォルダを、以下に置く:

~/Library/Application Support/Adobe/CEP/extensions/MCPBridgeCEP/

ターミナルで:

mkdir -p ~/Library/Application\ Support/Adobe/CEP/extensions
mv ~/Downloads/MCPBridgeCEP ~/Library/Application\ Support/Adobe/CEP/extensions/

Premiere Pro を起動

  1. PPro を起動
  2. メニュー: ウィンドウ → 機能拡張 → MCPBridgeCEP
  3. パネルが開いたら、「Start Bridge」ボタンをクリック
  4. 「Bridge running」表示が出れば OK

6. 動作確認

運用者に「接続できたか確認お願い」と伝える。
運用者側で /settings → 中継アプリ タブを開き、あなたの名前が 「オンライン」 になっていれば成功。

その後、運用者がテスト発注を作って動画生成を実行。あなたの Mac の PPro が自動で動き、Drive に動画がアップロードされれば完璧。

7. 普段の使い方

起動方法

Mac を再起動した後など、改めて中継アプリを起動するには:

cd ~/projects/cph-relay
npm run dev

（一度認証が完了していれば、再認証不要）

終了方法

ターミナルで Ctrl + C

通知

  • PPro が立ち上がっていない時は動画生成できないので、作業中は PPro 起動しておく
  • Mac がスリープに入ると中継停止する → 業務時間中はスリープ無効推奨（システム設定 → ロック画面 → ディスプレイのオフを「しない」）

トラブルシュート

npm install が失敗する

  • node-canvas でエラー: xcode-select --install で Xcode Command Line Tools を入れてから再試行
  • 権限エラー: sudo chown -R $(whoami) ~/.npm を実行

GitHub 認証画面で「ユーザーが見つかりません」

→ 運用者があなたの GitHub ユーザー名を cph に登録していない可能性。運用者に「GitHub ユーザー名 xxxx を登録してください」と伝える。

「CEP Bridge タイムアウト」エラー

  • PPro が起動していない
  • MCPBridgeCEP パネルで「Start Bridge」を押し忘れ
  • → PPro 起動 + Start Bridge をやり直す

Drive アップロードが失敗する

→ 出力先 Drive フォルダにサービスアカウントの権限が無い可能性。運用者に「Drive フォルダ共有してください」と伝える。

中継アプリが赤いエラーを出し続けている

→ ターミナルのエラーログを丸ごとコピーして運用者に送る。

連絡先

困ったら運用者に Slack/Chatwork で連絡。
