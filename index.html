静止画くん

動画生成 セットアップガイド

所要時間: 約30分

事前に必要なもの

  • Premiere Pro がインストール済み
  • 静止画くんのアカウント（招待済みのメールアドレス）
  • インターネット接続

1Node.js のインストール

  1. ターミナルを開く（Spotlight で「ターミナル」と検索）
  2. Homebrew をインストール:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

パスワードを聞かれたらMacのログインパスワードを入力

  1. 表示される Next steps の3行をコピペして実行
  2. Node.js をインストール:
brew install node@20
  1. 確認:
node --version
v20.x.x と表示されればOK
  1. https://nodejs.org/ja にアクセス
  2. LTS版（推奨版）をダウンロードしてインストール
  3. デフォルト設定のまま「Next」で進める
  4. コマンドプロンプトで確認:
node --version
v20.x.x と表示されればOK

2プロジェクトのクローン

mkdir -p ~/projects
cd ~/projects
git clone https://github.com/iwskmik/cph.git
cd cph
npm install

git が入っていない場合は brew install git を先に実行

Git がない場合: git-scm.com からインストール

mkdir %USERPROFILE%\projects
cd %USERPROFILE%\projects
git clone https://github.com/iwskmik/cph.git
cd cph
npm install

3環境設定ファイルの作成

プロジェクトフォルダ内に .env ファイルを作成し、以下を貼り付け:

DATABASE_URL="postgresql://ユーザー名@localhost:5432/cph?schema=public"
DIRECT_URL="postgresql://ユーザー名@localhost:5432/cph?schema=public"
NEXTAUTH_SECRET="dev-secret-key-change-in-production"
NEXTAUTH_URL="http://localhost:3000"
GOOGLE_SERVICE_ACCOUNT_KEY_PATH="./service-account-key.json"
ユーザー名 はPCのユーザー名に置き換えてください

4PostgreSQL のインストールと設定

brew install postgresql@15
brew services start postgresql@15
createdb cph
  1. postgresql.org からインストーラーをダウンロード
  2. インストール時のパスワードを覚えておく
  3. pgAdmin で cph データベースを作成

5データベースの初期化

npx prisma db push
npx tsx prisma/seed.ts
「Seed completed!」と表示されればOK

6サービスアカウントキーの配置

運用者から service-account-key.json を受け取り、プロジェクトフォルダ直下に配置:

cph/
├── service-account-key.json  ← ここ
├── package.json
├── src/
└── ...
このファイルは絶対にGitHubにプッシュしないでください

7CEP Bridge のインストール

Premiere Pro と連携するための拡張機能です。

CEPデバッグモードを有効化:

defaults write com.adobe.CSXS.12 PlayerDebugMode 1
defaults write com.adobe.CSXS.11 PlayerDebugMode 1
defaults write com.adobe.CSXS.10 PlayerDebugMode 1

CEP拡張ファイルを配置:

mkdir -p ~/Library/Application\ Support/Adobe/CEP/extensions/MCPBridgeCEP/CSXS

運用者から受け取ったファイル（manifest.xml, CSInterface.js, bridge-cep.js, index.html, .debug）を上記フォルダに配置

CEPデバッグモードを有効化:

  1. Win+R → regedit → Enter
  2. HKEY_CURRENT_USER\Software\Adobe\CSXS.12 に
    PlayerDebugMode = 1 (文字列) を追加

CEP拡張ファイルを配置:

C:\Users\ユーザー名\AppData\Roaming\Adobe\CEP\extensions\MCPBridgeCEP\

8動作確認

静止画くんの起動

cd ~/projects/cph
npm run dev

ブラウザで http://localhost:3000 を開く

ログイン画面が表示されればOK

Premiere Pro + CEP Bridge

  1. Premiere Pro を起動
  2. メニュー → ウィンドウ → エクステンション → MCP Bridge (CEP)
  3. Start Bridge をクリック
緑ドット2つになればOK

動画生成テスト

  1. ブラウザで localhost:3000/generate を開く
  2. .prproj のパスを入力してスキャン
  3. シーケンス選択 → テキスト選択 → 年齢設定
  4. 生成開始 → mp4 が出力されれば完了!

毎日の起動手順（3ステップ）

  1. ターミナル: cd ~/projects/cph && npm run dev
  2. ブラウザ: http://localhost:3000 を開く
  3. Premiere Pro 起動 → CEP Bridge で Start Bridge

トラブルシューティング

「サーバーに接続できない」
npm run dev が実行されているか確認してください。ターミナルが閉じていると停止します。
「CEP Bridge タイムアウト」
Premiere Pro が起動しているか、CEPパネルで Start Bridge が押されているか確認してください。
「テキストが .prproj 内に見つかりませんでした」
.prproj 内のテキストがスキャン結果と一致しているか確認。Premiere Pro で保存し直してから再スキャンしてみてください。
「H.264プリセットが見つかりません」
Premiere Pro 2024〜2027 がインストールされているか確認してください。
